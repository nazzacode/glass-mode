Websites, as glass.

A Zen Browser extension that turns the sites you live in (mail, calendar, chat, music) into translucent glass over your blurred desktop. One design system for every site, and a test lab that keeps every screen readable on any wallpaper.

Install

  1. Let Zen be transparent

    In Zen Browser open about:config and set to true:

    Linux
    browser.tabs.allow_transparent_browser · zen.widget.linux.transparency. The blur comes from your compositor: Hyprland blurs out of the box; KDE needs kwin-effects-forceblur.
    Windows 11
    browser.tabs.allow_transparent_browser · widget.transparent-windows · widget.windows.mica. Optional: MicaForEveryone with Acrylic for zen.

  2. Add the extension

    Download the .xpi from GitHub Releases, then in Zen: about:addons → ⚙ → Install Add-on From File.

  3. Optional: web apps

    Give a site its own chromeless window and launcher entry, glass straight through to the desktop (Linux):

    ./webapp/zen-webapp add "Gmail" https://mail.google.com --icon auto

One control

Everything follows a single variable: how much of the desktop shows through. Text, menus and panels keep their readability floors whatever you choose.

Popup slider
opacity 10–90 %, default 45 %
Alt Shift ↑ / ↓
more / less glass, in 5 % steps, in any window (web apps too)
Alt Shift G
glass mode: auto → dark → light

How it works

Every site style maps the site's own colours onto one shared set of glass tiers: frame (sidebars, top bars), content panes, popovers, fills and text. Each tier has a readability floor, because a compositor blur can't adapt to what's behind it the way Apple's glass does.

The test lab opens each screen headless, captures it over pure black and pure white to recover the exact colour and alpha of every pixel, composites that onto blurred wallpapers, and scores every text run with APCA against the darkest and brightest wallpaper. Surfaces must be design-system tiers, text must use the shared inks, and glass may never read worse than the site did natively. An explorer then opens menus, dropdowns, dialogs and search suggestions (read-only: never sends, deletes or posts) and scores each one the same way.

Add a site in one command

./glasslab add "Linear" https://linear.app/ --agent

Discovers what actually paints the page, scaffolds a style onto the glass tiers, then tests every screen and menu. With --agent a coding agent iterates until the tests pass. Or request a site: a maintainer labels it and CI opens the pull request. Details in docs/GLASS.md.
